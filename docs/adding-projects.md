# إضافة مشروع جديد

خطوات إضافة صفحة مشروع للموقع.

---

## ١. انسخ القالب

```bash
cp pages/project-boat.html pages/project-NAME.html
```

`project-boat.html` هو المرجع — يحتوي البنية الكاملة مع المجسم والسلة.

## ٢. عدّل رأس الصفحة

```html
<span class="lvl">متقدم</span>              <!-- سهل / متوسط / متقدم -->
<span class="cat">إنترنت الأشياء</span>
```

**فئات المستوى في CSS:**
```css

متوسط  → background:#FDF6B2; color:#C27803
متقدم  → background:#FDE8E8; color:#E02424
```

## ٣. اكتب الأقسام النصية

بالترتيب: المشكلة → كيف يشتغل → المميزات → التحديات.

**المشكلة:** لماذا هذا المشروع مهم — يفضّل ربطه بمشكلة أردنية حقيقية.

**كيف يشتغل:** ٤-٦ خطوات في `.how` كبطاقات.

**المميزات:** ٤-٥ نقاط تقنع لجنة المناقشة.

**التحديات:** ٤-٥ عقبات حقيقية. **لا تحذف هذا القسم** — يبني الثقة ويميّزنا.

## ٤. جهّز السلة

عدّل `PARTS` و `EXTRAS` في السكربت:

```javascript
const PARTS=[
 {id:'mcu', nm:'لوحة التحكم', req:true, qty:1,
  opts:[
   {k:'esp32', nm:'ESP32 DevKit', d:'واي فاي · الأنسب', p:18, def:true},
   {k:'nano',  nm:'Arduino Nano', d:'أرخص · بدون واي فاي', p:9}
  ]}
];
```

**قواعد:**
- بديل واحد على الأقل لكل مجموعة
- `def:true` للخيار الافتراضي — واحد فقط لكل مجموعة
- `d` يشرح **متى تختار هذا البديل** لا ما هو
- الأسعار بالدينار كأعداد صحيحة

## ٦. أضف المشروع للفهرس

في `pages/index.html`، أضف عنصراً لمصفوفة `P`:

```javascript
{id:'slug', c:'التصنيف', l:'m', ln:'متوسط', t:'الاسم',
 d:'وصف قصير للبطاقة',
 p:['قطعة','قطعة','قطعة'], cost:'٨٥'}
```

`l` يقبل: `e` سهل · `m` متوسط · `h` متقدم

## ٧. المجسم (اختياري)

المجسم يحتاج وقتاً — أضفه للمشاريع البارزة فقط.

**البنية:**
```javascript
const scene=new THREE.Scene();
const cam=new THREE.PerspectiveCamera(34,W()/H(),.1,300);
// خامات إجرائية → إضاءة → أرضية → القطع → حلقة الرسم
```

انسخ من `demos/boat-3d.html` أو `pages/project-wave.html`.

### تحذير مهم

**لا تستخدم `Object.assign` على كائنات Three.js:**

```javascript
// ❌ خطأ — يرمي TypeError ويوقف السكربت
scene.add(Object.assign(new THREE.DirectionalLight(0xfff,1),
  {position:new THREE.Vector3(1,2,3)}));

// ✅ صح
const light=new THREE.DirectionalLight(0xfff,1);
light.position.set(1,2,3);
scene.add(light);
```

خاصية `position` في `Object3D` معرّفة بلا setter — الإسناد المباشر يفشل.

**استثناء:** `Object.assign` على `shadow.camera` آمن (أرقام عادية).

## ٨. اختبار قبل النشر

```
□ افتح الصفحة — المجسم يظهر ولا شاشة سوداء
□ افتح console — لا أخطاء
□ شيّك وشيّل القطع — المجموع يتحدث
□ اضغط "أكّد الطلب" — رسالة واتساب صحيحة
□ صغّر النافذة — التصميم متجاوب
□ راجع الاتجاه RTL والأرقام العربية
```

## قائمة أفكار جاهزة للكتابة

مصنّفة حسب المستوى — تحتاج وصفاً وقطعاً فقط.

**سهل**
```
كشف تسرب الغاز مع إغلاق تلقائي
قفل باب ذكي بـ RFID
موقف سيارات ذكي
مراقبة جودة الهواء الداخلي
```

**متوسط**
```
عداد مياه ذكي يكشف التسريب
مراقبة استهلاك الكهرباء لكل جهاز
ثلاجة أدوية ذكية للصيدليات
مراقبة خزانات المياه
تتبع شحنات بـ GPS
نظام حضور بالتعرف على الوجه
```

**متقدم**
```
تتبع المواشي بتقنية LoRa
إنذار مبكر للسيول
مراقبة صحة خلايا النحل
مراقبة تشققات المباني
صيانة تنبؤية بتحليل الاهتزاز
كشف نعاس السائق
```

**برمجة**
```
كشف الانتحال بالنصوص العربية
تلخيص المحاضرات الصوتية
مساعد ذكي يجاوب من المستندات (RAG)
```

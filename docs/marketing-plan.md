# خطة التسويق الاجتماعي

هاي الأفكار من الشات اللي أرسلتوه (موقع تاني)، مطبّقة على موقعنا. الأجزاء اللي بالكود **انعملت**، والباقي شغل تسويقي عليكم.

## اللي انعمل بالموقع
- زر واتساب عائم بكل صفحة، برسالة جاهزة بتذكر المشروع اللي بيتصفحه الطالب.
- «ابعتلي قائمة القطع على واتساب» بكل سلة (بدون طلب): بيلتقط الطالب اللي لسا مش جاهز يشتري.
- «N طلاب نفّذوا هذا المشروع» تحت اسم كل مشروع (من التجارب المعتمدة بصور فقط).
- شارات للطلاب، وملف عام يشاركه الطالب بسيرته الذاتية (`/u?id=…`).
- صفحات جامعات (`/universities/…`) وصفحة سفير الجامعة (`/ambassador`).
- زر «شارك على إنستغرام» بكل مشروع: بيولّد صورة جاهزة (بورتريه ١٠٨٠×١٣٥٠) وبيشاركها من الموبايل أو بينزّلها.
- فوتر بروابط الموقع وواتساب، وسياسة الخصوصية والشروط (مسودتان).

## عليكم أنتم

### قناة واتساب (مشروع كل أسبوع)
- أنشئوا قناة باسم الشركة (Channels)، واجعلوا رابطها بالفوتر. الاشتراك مجاني وما بتحكمه خوارزمية.
- كل أسبوع: مشروع + صورة المجسم (الزر أعلاه) + سطر «شو بيحل؟» + رابط صفحته.
- ابدؤوا بمشاريع صورها جاهزة عندكم: القارب، العنكبوت، إشارة الإسعاف، الوريدي.

### ريلز/تيك توك (٣٠ ثانية، بدون كلام)
كل ريل لقطة نتيجة واحدة، ونهايتها اسم المشروع وكلمة «الرابط بالبايو»:
1. القارب عم بينظّف البركة.
2. الإشارة بتفتح الممر الأخضر لسيارة الإسعاف (وعندكم دِمو حي بالمدينة).
3. العنكبوت بيمشي على ٨ أرجل.
4. الوريدي: الكيس بيفضى ← الإنذار.
5. بوردة تتفكك وتتركب (زر «فكّك المجسم» على الشاشة).
6. جولة سريعة بالمدينة الليلية.

**ملاحظة:** لا تستعملوا فيديوهات أو صور أي جهة ثانية. صوّروا مشاريعكم أنتم بعلامتكم المائية.

### صور الطلاب
الصور المرفقة بالتجارب المعتمدة محتوى مجاني ومستمر. اطلبوا من كل طالب تنفّذ مشروعه ينشر تجربة بصور، وأعطوه نقاطاً (+١٠). بعد الموافقة، أعيدوا نشر أفضلها بحسابكم مع ذكره وإذنه.

### الجامعات
- صفحة كل جامعة جاهزة. شاركوها بمجموعات تلك الجامعة (واتساب/فيسبوك).
- **تنبيه SEO:** الصفحات الحالية بقالب متشابه مع تنويع بالاقتراحات. ليتصدّر أحدها بجوجل لازم يصير فيها محتوى حقيقي فريد (طلاب فعليون، مشاريع نُفّذت، مقابلات). لا تعتمدوا عليها وحدها.
- **السفير:** الصفحة تجمع الطلبات بواتساب بدون التزام. العمولة والمزايا لازم تُكتب باتفاق قبل التطبيق (ما وضعت أي رقم).
- معارض المشاريع بالجامعات: احضروا وصوّروا وعرضوا شغلكم، وخذوا أرقام الطلاب.

## ترتيب مقترح لأول شهر
| الأسبوع | الشغل |
|---|---|
| ١ | أنشئوا حساب إنستغرام + قناة واتساب، وضعوا الروابط (`INSTAGRAM` بـ `site/src/data/config.ts`) |
| ٢ | ٣ ريلز (القارب، الإشارة، العنكبوت) + أول ٣ منشورات بالقناة |
| ٣ | شاركوا صفحات ٥ جامعات بمجموعاتها + أول سفيران |
| ٤ | أول ٥ تجارب طلاب بصور، وأعيدوا نشرها |

## القياس
لا تحكموا بـ «عجبني». قيسوا: كم ضغطة على زر واتساب، كم «ابعتلي القائمة»، كم طلب فعلي، وكم تجربة معتمدة بصور بالأسبوع.
